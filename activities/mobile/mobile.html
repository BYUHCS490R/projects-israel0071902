1)The viewport meta tag is important because it helps the website display correctly on different screen sizes, especially mobile devices. It tells the browser how to control the page’s size and scaling so the content fits the screen properly and is easy to read.

2)I can adjust the CSS for printing by using the @media print rule in CSS. This allows me to change the style of the page when it is printed, such as hiding navigation bars, changing fonts, or adjusting colors to make the printed page cleaner and easier to read.

3)I would adjust the CSS for printing when I want the webpage to look better on paper. For example, I might remove menus, buttons, or images that are not needed when printing. This makes the printed page simpler, easier to read, and saves ink.

1)We need the viewport meta tag so the web page fits properly on phones and tablets. It helps the browser control the page width and scale, so the website looks correct on small screens instead of appearing zoomed out.

2)The CSS rule that comes later usually takes priority, if both selectors have the same specificity. So if flex-direction: row; is written after flex-direction: column;, then row will be used.

3)You can change the CSS for phones by using media queries. Media queries let you apply different styles for smaller screen sizes, such as changing layout, font size, width, or flex direction for mobile devices.
