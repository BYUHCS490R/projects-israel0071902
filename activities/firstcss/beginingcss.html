Begining Css

    1. Inline CSS means writing CSS inside the HTML tag. It is used to change only one element. For example, it can change the color of one paragraph. Inline CSS is not good because it makes the code messy and hard to change
    2. CSS means writing CSS inside the (style) tag in the HTML file. It is used to style one full page. But it works only for that page. If we have many pages, we must write the same CSS again and again.
    3. External CSS is written in a separate .css file and linked to the HTML file. This is the best way to use CSS. One external CSS file can be used for many pages and keeps the code clean.
  2. I think we should use only external CSS because it is easy to edit, saves time, and is professional. If we change one CSS file, all pages will change.
  3. A selector is used to choose which HTML element we want to style. In simple words, a selector tells CSS what to change.
