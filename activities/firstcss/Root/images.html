Images

Answer Questions

1 ) JPEG is best for real-world photos such as landscapes, portraits, and photos with lots of colors and gradients. It compresses images well, keeping file sizes small, but it loses some quality.

2 ) GIF is good for simple images with few colors, such as logos, icons, and small animations. It supports animation but only allows up to 256 colors.

3 ) PNG supports lossless compression and transparency. This means image quality is preserved and backgrounds can be transparent, making it great for logos and graphics.

4 ) I resize my photos using photo editing software such as Pixlr, Paint, or Photoshop. These tools allow me to change the image dimensions before uploading it to the website, so the image fits correctly and loads faster.

5 ) Resizing images using CSS does not reduce the file size, so the browser still downloads the large image. Photo editing software reduces file size and improves website loading speed.

6 ) CSS validation checks your CSS code for errors and ensures it follows web standards. Valid CSS helps websites work consistently across different browsers.
