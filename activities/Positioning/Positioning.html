Engagement - Positioning

  1. Normal flow in HTML is the basic way a web page is arranged. The elements go from top to bottom. Headings and paragraphs start on a new line. Links and small items can stay on the same line. This is how the page works before we use CSS.
  2. The float property moves an element to the left or right side of the page. When we use float, text can go around the image or box. We use clear to stop the text from wrapping around it. Clear makes the next content move below the floated element.
  3. Relative positioning moves an element a little from its normal place. Absolute positioning places an element in an exact spot inside its parent. Fixed positioning keeps an element in the same place on the screen, even when we scroll.
  4. We can make nice navigation buttons for mobile devices by making them bigger and adding space inside them. We can also place the buttons one below another so they are easier to tap on a phone. Using simple colors and responsive design helps the website look good on small screens.
  5. We can find videos to review the lesson on the class website, in the course materials, and on websites like YouTube and W3Schools.
