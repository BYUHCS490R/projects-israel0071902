1)I learned that CSS is used to style and design a website. It controls colors, fonts, spacing, size, and layout. Flexbox is a part of CSS that helps arrange items easily on a webpage. I learned that justify-content moves items left and right, and align-items moves items up and down. We can use values like center, flex-start, flex-end, space-between, and space-around to control position and spacing. Flexbox makes layout simple and organized.

2)I reached Level 20 in the Flexbox Froggy game. The levels became harder, and I learned how to use different properties together. The game helped me understand Flexbox better by practicing and trying different combinations.
