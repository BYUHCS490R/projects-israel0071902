CSS Selectors

The different ways to select an item in CSS are tag selectors, ID selectors, class selectors, child selectors, and the universal selector.

An ID uses the # symbol and is unique to one element, while a class uses the . symbol and can be used on multiple elements.

A span tag is an inline element used to style part of text, while a div tag is a block-level element used to group and structure content.

A div tag is a generic container with no semantic meaning, while header, main, and footer are semantic tags that describe the purpose of the content.

Colors in CSS can be selected using color names, hexadecimal values, RGB, and RGBA values.
